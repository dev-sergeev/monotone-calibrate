# Монотонная аппроксимация кривой

Контекст описывает язык подбора одной интерпретируемой кривой к табличным наблюдениям с координатами `x` и `y`.

## Language

**Кусочная аппроксимация**:
Одна кривая, составленная из функций, каждая из которых действует на своём последовательном интервале `x`.
_Avoid_: Кластеры точек, независимые кривые

**Сегмент**:
Последовательный интервал `x`, описываемый одной функцией кусочной аппроксимации.
_Avoid_: Кластер, группа наблюдений

**Точка сопряжения**:
Граница соседних сегментов, в которой их функции по умолчанию образуют непрерывное соединение.
_Avoid_: Центр кластера, произвольная граница

**Глобальная монотонность**:
Единое направление изменения кусочной аппроксимации на всей области `x`, сохраняющееся внутри сегментов и при переходе между ними.
_Avoid_: Локальная монотонность отдельных несогласованных функций

**Диагностическая граница качества**:
Значение `R² = 0,60` для всей кусочной аппроксимации, ниже которого результат обязательно сопровождается явным предупреждением пользователю, но не скрывается и не объявляется автоматически недопустимым.
_Avoid_: Жёсткий порог успеха, качество отдельной точки

**Минимально достаточная модель**:
Одна функция либо сбалансированная модель из двух функций; второй сегмент оправдан только устойчивым улучшением проверочного качества и устранением систематической ошибки.
_Avoid_: Модель с максимальным обучающим R², модель с тремя сегментами

**Сбалансированное разбиение**:
Разбиение на два сегмента, при котором каждый сегмент содержит не менее 40% наблюдений; тем самым допустимое соотношение размеров лежит между `40/60` и `60/40`.
_Avoid_: Точное разбиение 60/40, малый служебный сегмент, разбиение 5/95

**Отчёт о калибровке**:
Сравнительное заключение, показывающее качество односегментной модели, качество каждого сегмента и общий `R²` двухсегментной модели, величину улучшения, обязательные графики и финальную рекомендацию.
_Avoid_: Единственная метрика без локальной диагностики, результат без сравнения кандидатов

**График калибровки**:
Scatterplot исходных наблюдений с линиями кандидатных аппроксимаций; границы сегментов двухсегментной модели явно обозначены красными линиями, а функция каждого сегмента показана только внутри его интервала.
_Avoid_: График без исходных точек, неразличимые границы сегментов, экстраполяция сегментной функции за её интервал

**Улучшение модели**:
Прирост проверочного качества двухсегментной модели относительно односегментной, достаточный для оправдания дополнительной сложности.
_Avoid_: Рост обучающего R² сам по себе

**Проблемное наблюдение**:
Точка с аномально большим остатком относительно рекомендованной модели, которая должна быть подсвечена в отчёте, но не исключена из анализа автоматически.
_Avoid_: Точка с собственным R², автоматически удалённый выброс

**Невалидная строка**:
Строка входной таблицы, в которой `x` или `y` отсутствует, не является числом либо не является конечным числом; она не считается наблюдением для подбора, но остаётся частью аудита входа.
_Avoid_: Проблемное наблюдение, молча удалённая точка

**Идентификатор строки**:
Стабильная ссылка на исходную строку таблицы, сохраняющая связь наблюдений, исключений и предупреждений с входными данными независимо от сортировки и фильтрации.
_Avoid_: Порядковый номер после очистки, индекс отсортированной таблицы

**Группа совпадающих x**:
Все отдельные наблюдения с одним и тем же значением `x`; при выборе точки сопряжения такая группа неделима и целиком относится к одному сегменту.
_Avoid_: Усреднённая точка, разделённая группа

**Низкое разрешение x**:
Случай, когда `x` остаются различными binary64-значениями, но их ULP велик относительно полного диапазона; fit использует фактически представленные значения и выдаёт warning вместо округления или ложного объединения.
_Avoid_: Постоянный x, автоматическое округление близких координат

**Реестр функций**:
Версионируемый конечный набор канонических семейств, из которых могут состоять рекомендуемые аппроксимации.
_Avoid_: Все элементарные выражения, неограниченная символьная грамматика

**Портфель гипотез**:
Конечное замороженное подмножество типизированных P1-семейств и ordered P2-пар из реестра, внутри которого локальный solver выбирает и оценивает калибровочную функцию.
_Avoid_: Готовые коэффициенты от LLM, произвольный исполняемый код, незамороженное пространство в validation

**LLM-SR-поиск**:
Опциональный итеративный выбор портфеля гипотез по отрицательному MSE и scored experience; числовые параметры, точка сопряжения и сертификаты остаются ответственностью локального solver.
_Avoid_: Генерация исполняемой формулы, замена проверочного контура внешней моделью

**Сертифицированная функция**:
Каноническая функция из реестра, для которой на всём заявленном интервале подтверждены область определения, конечность и требуемое направление монотонности.
_Avoid_: Функция, проверенная только в наблюдаемых точках

**Схлопывание модели**:
Приведение вырожденной или практически неразличимой сложной формы к эквивалентной более простой канонической модели.
_Avoid_: Удаление неудобного кандидата, округление коэффициента без проверки

**Проверочное качество**:
Качество полной процедуры подбора, измеренное по прогнозам для наблюдений, чьи `y` не участвовали ни в выборе формы, ни в оценивании её параметров.
_Avoid_: Обучающее качество, метрика уже выбранной на всех данных формулы

**Описательная аппроксимация**:
Формула, подобранная для представления имеющихся точек, когда данных недостаточно для проверочной рекомендации.
_Avoid_: Подтверждённая рекомендация, доказанное обобщение

**Практически значимый uplift**:
Заранее определённое устойчивое улучшение проверочного качества P2 относительно P1, достаточное для оправдания второй функции.
_Avoid_: Любое положительное изменение R², рост обучающего качества

**Проверочный остаток**:
Разность наблюдаемого `y` и прогноза, полученного процедурой, которая не использовала `y` этой строки при подборе формы и параметров.
_Avoid_: Остаток финального refit, обучающая ошибка

**Влияющая группа**:
Группа совпадающих `x`, исключение которой в отдельном sensitivity-run существенно меняет форму, качество, границу или рекомендацию.
_Avoid_: Строка с большим остатком, автоматически удаляемый выброс

**Диагностический флаг**:
Прослеживаемая отметка причины для проверки наблюдения или модели, не изменяющая текущую аппроксимацию и имеющая действие только `review_only`.
_Avoid_: Команда удаления, доказательство ошибки данных

**Пакет отчёта**:
Неизменяемый локальный каталог одного завершённого запуска, содержащий human report, machine state, модели, таблицы, графики, trace, provenance и проверяемый manifest.
_Avoid_: Одиночная картинка, перезаписываемая папка, незавершённый рабочий каталог

**Артефакт рекомендованной модели**:
Типизированное JSON-представление подтверждённой P1/P2-рекомендации с семействами, параметрами, интервалами и сертификатами, которое оценивается versioned predictor без исполнения строки формулы.
_Avoid_: `eval` отображаемой формулы, описательная модель без validation recommendation

**Идентификатор анализа**:
Стабильный hash логического входа, policy, registry, source artifact, dependency lock и seeds; operational timestamp, путь и runtime в него не входят.
_Avoid_: Идентификатор экземпляра отчёта, время запуска
