# Проверка новых формул через OpenRouter, 2026-09-12

Модель: `deepseek/deepseek-v4-flash-0731`. `reasoning.effort=none`, JSON mode, максимум 4096 выходных токенов на запрос. Токен и сырые ответы в этом документе не сохраняются.

Это интеграционные проверки на синтетических development fixtures, не независимый benchmark превосходства LLM. Внутри каждого запуска поиск видит только training split; общей контрольной выборке соответствуют отдельные сохранённые модели до полного refit.

В первом примере новая формула точнее на этих контрольных точках; во втором выигрывает алгоритмическая P2. Итог не предполагает обязательной победы LLM.

Оба пакета прошли `verify`: 12 артефактов в каждом, пересчитаны refit/holdout метрики и прогнозы. Загрузка `model-llm.json` и `predict` проверены на трёх точках внутри диапазона, одной вне диапазона и одной нечисловой строке: `3 OK / 1 OUT_OF_DOMAIN / 1 INVALID_X`. Дополнительная плотная сетка из 10001 точки подтвердила монотонность обеих итоговых формул; основной сертификат остаётся структурным.

Исходные fixtures генерируются детерминированно:

```python
import numpy as np
# Плавная корневая зависимость
x = np.linspace(0, 10, 60)
y = 1.5 + 4*(np.sqrt(1+3*x/10)-1) + np.random.default_rng(731).normal(0, .006, x.size)
# Два корневых режима с непрерывным стыком
x = np.linspace(0, 10, 80)
left = (np.sqrt(1+2*np.minimum(x,5)/5)-1)/(np.sqrt(3)-1)
right = (np.sqrt(1+5*np.maximum(x-5,0)/5)-1)/(np.sqrt(6)-1)
y = np.where(x <= 5, 3+1.2*(left-1), 3+5*right) + np.random.default_rng(129).normal(0, .008, x.size)
```

Первый прогон: четыре итерации LLM, второй: три. Обе проверки использовали `--validation-repetitions 2 --bootstrap-resamples 40`; default OOF budget остаётся 10/200. Общий holdout определяется отдельной политикой `grouped-interpolation-holdout-v1`. Ответы LLM стохастические, повтор не обязан найти ту же структуру.

В процессе проверки выявлены и учтены два ограничения провайдера: default high reasoning исчерпывал 4096 токенов до JSON; рекурсивный strict JSON Schema давал тривиальные деревья `t`. Проверка формул осталась строгой и локальной. В корректном JSON невалидная гипотеза теперь отклоняется отдельно, не удаляя допустимых соседей.
